# 🔌 Portfólio de Infraestrutura de TI e Cable Management

Bem-vindo ao meu portfólio de projetos físicos de TI! 

Como estudante de Análise e Desenvolvimento de Sistemas (ADS), compreendo que a organização, a arquitetura limpa e o "clean code" são pilares para o sucesso de um software. Este repositório tem como objetivo demonstrar como aplico esses mesmos princípios no mundo físico (Hardware e Redes), estruturando racks e ativos de rede para garantir eficiência, segurança e facilidade de manutenção.

## 🛠️ Boas Práticas e Metodologia
A reestruturação de um rack vai além da estética. Em todos os projetos listados abaixo, foco nas seguintes práticas:
- **Otimização de Fluxo de Ar:** Organização inteligente para evitar o superaquecimento dos switches e servidores.
- **Redução de Downtime:** Padronização pensada para agilizar o *troubleshooting* (resolução de problemas) e trocas de equipamentos.
- **Mapeamento:** Etiquetagem e rastreabilidade para garantir que qualquer técnico consiga operar a infraestrutura futuramente.
- **Isolamento:** Separação adequada entre cabos de dados e de energia.
